# Небесный Куш — космический слот

Бесплатная игра на виртуальные монеты. 18+, только для развлечения.
Монеты не имеют денежной ценности, их нельзя вывести, обменять или передать.

## Как запустить на компьютере (Windows)

1. Один раз установить **Node.js LTS**: https://nodejs.org → большая зелёная кнопка «LTS» → установить с настройками по умолчанию.
2. Открыть папку проекта в Проводнике, в адресной строке набрать `cmd` и нажать Enter — откроется чёрное окно уже в этой папке.
3. Один раз набрать: `npm install`
   Или просто дважды щёлкни файл **start.bat** — он сделает шаги 3–4 сам.
4. Запуск игры: `npm run dev` → открыть в браузере http://localhost:5173
   - режим приложения с тестовой рекламой и магазином: http://localhost:5173/?app=1
   - остановить: в чёрном окне нажать Ctrl+C

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт локально |
| `npm test` | быстрые проверки логики (Vitest) |
| `npm run rtp` | симуляция 1 000 000 вращений, проверка RTP 95% |
| `npm run e2e` | проверка в браузере на экране 390×844 (первый раз: `npx playwright install chromium`) |
| `npm run build` | готовый сайт в папке `dist` |

## Где что лежит

- `src/config.js` — ВСЕ числа экономики (бонусы, ставки, пакеты, выплаты слота)
- `src/storage.js` — баланс и прогресс (сейчас в браузере, позже Firebase)
- `src/platform.js` — сайт или приложение (`IS_APP`)
- `src/ads.js`, `src/shop.js` — реклама и покупки (только в приложении, пока заглушки)
- `src/slot/engine.js` — математика слота, `src/slot/symbols.js` — рисунки символов
- `src/bonus.js` — ежедневный, спасательный бонус, видео за награду
- `src/progress.js` — уровни и достижения
- `tools/rtp.js` — симуляция RTP
